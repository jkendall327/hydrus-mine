- An assertion whose two sides both come from the test is circular. Expected values come from the recording.
- A leaf you can't finish gets no tag, plus a DIFFERENCES.md line saying what's missing. Never raise a recheck class beyond what the test proves.
- Add or update a recheck record in docs/rust/tracking/leaves.json for each leaf you work on ({date, class, by, note}; see docs/rust/tracking/README.md). The note says exactly what the test proves and what it doesn't.
