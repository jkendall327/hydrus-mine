Scope, evidence and keeping this map current

Curated assessments. First pass identifies a supported native slice with existing reference evidence. Partial has known limitations. Missing identifies a placeholder or unsupported slice. Unassessed leaves behavior open. The generator validates structure and source anchors; it does not run behavior tests or assign statuses.

Reference features organize selected user-visible behaviors. Native surfaces organize menus and concrete window occurrences. A dialog may be partial while its particular workflow has a first pass. Candidate mappings between views require review and do not assert equivalence.

Counting. Nested descendants exclude the selected node and follow containment only. Unique nested features count concrete descendants, excluding organizational menus, roots and shared alias occurrences. Reachable features include the selected concrete feature and follow shared-editor links once with cycle protection. Alternative entrypoints are navigation links, never containment edges.

No remote assets or requests are needed to use this file. Source links open the exact commit stored in the selected inventory. Evidence is recorded evidence, not a claim that checks were run while building this map.

Maintainers: edit the canonical snapshots with source-backed statuses, then run python3 scripts/gui_coverage.py. See the maintenance notes.
